# Portfolio 極簡重構設計

日期：2026-08-10
標的：`index.html`（現行 683 行單檔）

## 目標

把現行 portfolio 重構為五個方向並存的單頁網站：極簡設計、微互動、scroll storytelling、WebGL 動畫、無障礙、green web design。

WebGL 與 green web design 在能耗上直接衝突。本設計的解法是：**WebGL 只有一處，並由七道閘門控制是否載入與執行**。完成後的持續耗電應低於現行版本，因為現行版本有三顆 `filter: blur(70px)` 的無限循環動畫（`index.html:162-164`），捲出畫面仍持續佔用 GPU 合成。

## 現況問題

| 問題 | 位置 |
| --- | --- |
| 手機版導覽連結全部 `display:none`，行動裝置只剩 Contact | `index.html:125` |

| 無 `:focus-visible` 樣式，深色底上焦點幾乎不可見 | — |

| `--text-muted: #64748b` 在 `--bg: #f4f6fb` 上約 4.4:1，用於 `0.78em` 的 `.ci-label` 過險 | `index.html:30, 371` |
| emoji（🎓💼📧🐙📍）無 `aria-hidden`，被螢幕閱讀器逐字唸出 | 多處 |

### 能耗

- 一次載入三個 Google Fonts 家族、八個字重，第三方阻塞請求（`index.html:20`）
- 三顆 `filter: blur(70px)` 元素無限循環動畫，離開視窗仍執行（`index.html:162-164`）
- 全域 `scroll-behavior: smooth`（`index.html:70`）

### 設計

現行視覺與「極簡」相反：三層漸層、glassmorphism 導覽列、四處 `box-shadow`、卡片容器、emoji 圖示。元素多但層級不強。捲動只有 `.reveal` 淡入，沒有敘事推進。

## 決策

| 項目 | 決定 |
| --- | --- |
| WebGL | 單一焦點（Hero）+ 嚴格能耗閘門。原生 WebGL，不引入 three.js |
| 極簡程度 | 紀錄片式：移除卡片、陰影、漸層、emoji |
| 敘事主線 | 手工 → 自動化的轉化 |
| 字體 | `system-ui` 堪體 + 自托管單一 subset 等寬體 |
| 強調色 | 墨綠 |

## 架構

```
index.html          結構與內容
css/main.css        樣式
js/main.js          微互動、主題、捲動觀察
js/hero-gl.js       WebGL，僅在通過能耗閘門時 fetch
fonts/mono.woff2    subset 等寬體
```

拆檔的理由是 green，不是整潔。`hero-gl.js` 必須獨立成檔，才能在不該執行的裝置上完全不下載。內嵌於 `index.html` 的 shader 程式碼即使不執行也已傳輸。

託管維持 GitHub Pages 靜態託管，不新增建置步驟。

## 視覺系統

### 色彩

全站三個角色，取代現行 5 個色變數與 2 個漸層。

| 角色 | Light | Dark |
| --- | --- | --- |
| 背景 | `#fbfbfa` | `#0d0d0e` |
| 文字 | `#16161a` | `#ececea` |
| 次要文字 | `#5c5c66` | `#9a9aa4` |
| 分隔線 | `#e4e4e0` | `#26262b` |
| 強調色 | `#15803d` | `#4ade80` |

對比度：`#15803d` 於 `#fbfbfa` 為 4.84:1（AA 通過）；白字於 `#15803d` 為 5.01:1；`#4ade80` 於 `#0d0d0e` 為 11.15:1。實作時逐一以工具複驗；若 `#15803d` 在小字級上餘裕不足，改用 `#14532d`。

深色模式背景壓到接近真黑，供 OLED 省電。加 `<meta name="color-scheme">` 消除載入白閃。

### 排版與元素

- 移除全部 `box-shadow`、漸層、`.panel` 與 `.card` 容器、glassmorphism 導覽列、全部 emoji
- 區塊分隔改用 1px 髮絲線與大留白
- 圖示改為 `currentColor` 的 inline SVG，沿用現行 footer 三個 social SVG 的線性風格
- 內文走 `system-ui` 堪體：零請求、零 FOUT
- 自托管一個 subset 等寬體，僅供數字、年份、標籤使用。字符集限 `0-9 . % $ – → A-Z`，目標 8-10KB。它是「自動化」主線的視覺記號

## 敘事骨架

現有內容不新增，只重新組織為五幕。

**幕 0 — Hero。** WebGL 呈現一團無序的點，代表「手工」。標題、一句定位、兩個 CTA。

**幕 1 — 混亂。** 重寫的 About。大字排版：`15 種格式 · 3 天 · 手工`，用等寬體。問題陳述。

**幕 2 — 收斂。** Projects。三個專案各是一次收斂。主體呈現為 before → after 的數字轉場：`3 days → under 1 hour`、`~2% → near-zero`。這兩組數字現行已有，只是埋在條列中，拉出來當主角。

**幕 3 — 路徑。** Timeline。現有時間軸內容原樣保留，去掉卡片容器，改髮絲線。

**幕 4 — 現在。** Skills 與 Contact 合併收尾。

### 支點

捲過 Hero 時，那團無序的點逐漸對齊成規則網格。

這一個效果同時是 WebGL 的唯一用途、scroll storytelling 的主軸、以及「手工 → 自動化」的字面視覺化。它取代現行的三顆光暈與所有漸層，屬於替換而非加法。

## 微互動

1. 數字捲入時 count-up，每個數字只跑一次
2. 連結 hover 底線由左畫出，用 `transform: scaleX`（GPU 成本低），非顏色跳動
3. 主題切換走 View Transitions API 做圓形擴散，不支援時直接切換
4. 時間軸的線隨捲動繪出，用 CSS 原生 `animation-timeline: view()`，零 JS
5. 導覽列標示當前 section，用 IntersectionObserver
6. 點擊 email 直接複製到剪貼簿，就地顯示 `Copied`
7. 全站統一 `:focus-visible` 焦點環：2px outline + offset

全部微互動須在 `prefers-reduced-motion: reduce` 下降級為無動畫的等效行為（功能保留，位移與淡入移除）。

## WebGL 能耗閘門

實作方式：原生 WebGL，單一 draw call 的 `gl.POINTS`。粒子數依螢幕面積計算，上限 2000。目標 3-5KB。

### 載入閘門

任一條件成立即不 fetch `js/hero-gl.js`，改顯示靜態 SVG 替代圖。替代圖是動畫終態的靜止版本——已對齊的規則網格——直接內嵌於 `index.html`，並標 `aria-hidden="true"`。它同時是 WebGL 版本的載入前佔位，避免版面跳動。

閘門條件：

1. `prefers-reduced-motion: reduce`
2. `navigator.connection.saveData` 為 true
3. `navigator.deviceMemory <= 4` 或 `navigator.hardwareConcurrency <= 4`
4. 無法取得 WebGL context
5. Battery API 可用，且電量 < 20% 且未充電

閘門 3 與 5 依賴的 API 並非所有瀏覽器都提供。API 不存在時視為「未觸發」，繼續載入——不因偵測不到而保守停用，也不因偵測不到而假設裝置強悍。

### 執行期節流

6. Hero 離開視窗時 `cancelAnimationFrame`；`document.hidden` 時同樣停止
7. 上限 30fps，不跑 60fps

Canvas 標 `aria-hidden="true"`，它是純裝飾，不承載資訊。

## 無障礙修復

| 問題 | 修法 |
| --- | --- |
| 手機無導覽 | 改底部 sticky 導覽，移除 `display:none` |
| 無 skip link | 加入，聚焦時可見 |
| 焦點不可見 | 全站統一 `:focus-visible` |
| 主題鈕無狀態 | `aria-pressed` + `aria-live` 播報 |
| emoji 被逐字唸 | 全部移除，改 inline SVG 並標 `aria-hidden` |
| 高對比模式文字消失 | 漸層文字隨極簡一併移除，加 `@media (forced-colors: active)` 檢查 |
| 假連結 | Location 改 `<address>`，視覺與連結區隔 |
| 對比不足 | 次要文字提升至 7:1 |

驗收標準：鍵盤可完整操作全站、螢幕閱讀器閱讀順序合理、所有文字達 WCAG AA（正文 ≥4.5:1，大字 ≥3:1）。

## Green 措施與目標

- 移除 Google Fonts：省三次 DNS/TLS 交握與約 90KB，第三方請求歸零
- 移除三顆 blur 無限動畫
- WebGL 惰性載入並受閘門控制
- 深色模式接近真黑，OLED 省電
- `<meta name="color-scheme">` 消除白閃
- 保留現行的 data URI SVG favicon（`index.html:16`），但改為與新視覺一致的圖形，不再是 emoji
- 全域 `scroll-behavior: smooth` 改為只作用於錨點導覽（`@media (prefers-reduced-motion: no-preference)` 內），避免長距離捲動時的持續重繪

驗收目標：

- 首次載入 < 60KB（含字體）
- Lighthouse Performance ≥ 98
- 第三方請求 0

三項均需實測，不接受估算。
